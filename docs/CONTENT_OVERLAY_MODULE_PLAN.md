# 内容蒙版模块方案

## 目标

内容蒙版是编辑器预览中的只读分析信息层。它随播放头切换到当前分镜，展示用户选择的镜号、时间码、分镜时长、画面内容和模板分析字段，帮助拉片时把“画面”和“结论”放在同一观察面中。

它与构图蒙版是两个独立模块：

- 构图蒙版用于画面辅助、绘制与分镜截图导出。
- 内容蒙版用于阅读当前分镜的结构化分析数据。
- 内容蒙版不参与视频像素渲染、分镜截图、报告导出或构图蒙版的编辑历史。

## 调研结论

- MDN 确认 `pointer-events: none` 可让覆盖元素不成为指针事件目标；内容蒙版可安全叠加在视频上而不阻挡播放、平移与构图编辑。
- OpenReel 将实时预览、文本叠层和交互层分开，叠层内容按当前时间解析，而不让 UI 自行维护时间。
- OpenCut 使用独立的预览覆盖层，区分场景坐标和视窗 HUD 坐标，并按显示平面和层级排序。
- 旧 AisenLens 的构图层使用归一化画面坐标；这适合可编辑几何图形，但内容蒙版的首版不需要自由拖拽或坐标编辑。

## 首版范围

### 可显示信息

- 镜号：`SHOT 01`。
- 当前播放头时间码与当前分镜时长（秒）。
- 画面内容与镜头分析：分别对应当前分镜描述和分析批注，可单独选择显示。
- 模板字段：从项目模板中多选，按模板排序显示。

字段值统一格式化：多选值以 `·` 连接，布尔值显示“是/否”，数字保留原值，未填写字段不渲染。长文本最多显示两行，超出截断，避免遮住视频。

### 布局与样式

提供三种经过约束的布局，不做自由拖拽：

| 布局 | 位置 | 内容 |
| --- | --- | --- |
| `compact` | 左上 | 镜号、时间码、已选字段标签 |
| `sidebar` | 左侧纵栏 | 镜号、时长、字段列表、画面内容摘要 |
| `lower-third` | 左下 | 镜号与重点字段，适合演示观看 |

- 以半透明深色面板、细边框和 `backdrop-blur` 保证深浅主题下可读性。
- 使用现有编辑器字号：标签 10px、正文 11px、镜号/时间码 12px 等宽字体。
- 默认关闭；启用后默认 `compact`，预选镜别、运动方式、色调、声音设计和剪辑节奏中有值的字段。
- 仅允许选择最多 6 个字段；画面内容单独开关，防止堆叠过密。

## 数据结构与持久化

在 `src/features/content-overlay/types.ts` 定义：

```ts
type ContentOverlayLayout = "compact" | "sidebar" | "lower-third";

interface ContentOverlaySettings {
  enabled: boolean;
  layout: ContentOverlayLayout;
  fieldIds: string[];
  showShotNumber: boolean;
  showTimecode: boolean;
  showDuration: boolean;
  showDescription: boolean;
  showAnalysis: boolean;
  showBackground: boolean;
  backgroundOpacity: number;
}
```

- 设置属于项目级偏好，加入 `ProjectRecord`，由现有项目仓储规范化后保存。
- 当前分镜值始终从已经持久化的 `ShotRecord.analysisFields`、`description` 与模板快照派生；不复制字段文本或分析结果。
- 模板字段被删除后，规范化时移除无效 `fieldIds`；字段改名会自动使用新标签。
- `DEFAULT_CONTENT_OVERLAY_SETTINGS` 为关闭状态，保证首次进入不改变当前预览。

## 渲染架构

```text
EditorWorkspace
  ├─ 当前分镜 + 模板 + 分析字段
  ├─ 内容蒙版设置面板
  └─ VideoPreviewCanvas
       ├─ 视频画面（object-contain）
       ├─ 构图蒙版（可编辑 SVG）
       └─ 内容蒙版（只读 DOM，pointer-events: none）
```

- `ContentOverlay` 只接收已解析的展示模型，不访问仓储，也不保存业务数据。
- `contentOverlayResolver` 负责字段排序、字段值格式化、空值过滤和文本截断，保持组件纯渲染。
- 内容层挂载在真实视频画面容器内，和 `object-contain` 的视频画面同尺寸；不覆盖画布比例产生的留白。
- 构图编辑时内容层仍可显示但不接收事件；所有构图的指针交互保持不变。
- 缩放、平移、全屏与画布比例变化直接复用现有视频容器变换，无须额外坐标换算。

## 交互入口

在左侧“视频蒙版”工具中区分两个折叠区：

1. **构图辅助**：保持现有功能与设置。
2. **分析信息**：总开关、布局、信息项开关、字段多选。

不新增视频预览上的常驻按钮；用户从工具栏统一管理，避免预览控制栏继续膨胀。

## 实施阶段

1. 建立 `features/content-overlay` 的类型、默认值和展示模型解析服务。
2. 扩展项目记录、仓储规范化和统一保存快照，让项目级设置持久化。
3. 实现只读 `ContentOverlay`，接入 `VideoPreviewCanvas` 的真实视频画面层。
4. 在视频蒙版面板中加入紧凑配置区，复用现有 Button、Switch 风格和模板字段。
5. 验证分镜切换、字段编辑、模板增删改、缩放/平移、全屏、横竖画布与深浅主题。
6. 执行 `pnpm.cmd build`，并做一次截图导出回归，确认内容层不会出现在分镜截图中。

## 明确不做

- 不做自由拖拽、任意坐标、单字段独立颜色或动画。
- 不在截图、导出报告或视频文件中烧录内容蒙版。
- 不新增多轨字幕、可编辑文本片段或 Canvas 合成链路。
- 不引入新依赖。
