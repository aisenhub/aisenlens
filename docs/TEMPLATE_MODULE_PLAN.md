# 分析模板模块拆分计划

## 范围

将编辑器原有硬编码分析维度升级为项目级模板快照。模板定义字段、可选项与参考词；分镜仅用稳定字段 ID 保存填写值。

| 阶段 | 落点 | 工作 | 状态 |
| --- | --- | --- | --- |
| T1 | `features/template/types.ts` | 模板、字段、选项与参考词类型 | [x] |
| T2 | `features/project/services/projectRepository.ts` | IndexedDB 项目模板快照仓库 | [x] |
| T3 | `features/template/services/defaultTemplate.ts` | 初次打开项目时创建基础模板快照 | [x] |

| T6 | `features/editor/components/EditorWorkspace.tsx` | 编辑模板名称、字段、选项、参考词与新增字段 | [x] |
| T7 | 验证 | 生产构建与浏览器手动验证 | [~] |

## 已确认规则

- 每个项目只有一个正在使用的模板快照；项目首次打开时创建默认快照。
- 分镜分析值始终按 `TemplateField.id` 保存，展示名称可更改但不会改变已保存值的键。
- 选项是可保存值的约束集合；参考词只提供思考提示，不会自动写入分镜。
- 固定字段 `shot_description` 保留在模板中，并对应现有“画面内容”笔记；本阶段不重复生成第二份字段值。
- 默认模板包含景别、运动方式、色调、声音设计与剪辑节奏；新建字段目前为单选字段。

## 参考结论

- 成熟 schema 方案采用稳定属性键、明确字段类型和选择值约束。
- OpenReel 的模板是视频创作资源/占位符替换，OpenCut 主要是固定属性面板，均不适合直接复用为拉片分析字段模板。
- 因此 AisenLens 使用独立项目快照和稳定字段 ID，不迁移两个项目的模板实现。

## 手动验证

1. 打开编辑器左侧“模板”，修改模板名称、字段名称、选项或参考词。
2. 在右侧“维度”面板确认改动立即生效；选择一个选项后刷新，确认值仍存在。
3. 新增字段，刷新后确认字段与填写值仍存在。
# 模板与分析字段模块拆分计划

## T8 字段管理与动态输入（已完成）

- [x] 模板编辑移入独立弹窗；编辑器侧栏只显示当前项目模板摘要和入口。
- [x] 模板字段支持 `single-select`、`multi-select`、`text`、`number` 与 `boolean` 五种类型。
- [x] 自定义字段可新增、上移、下移与删除；固定字段不可改名、改类型、移动或删除。
- [x] 分镜分析值按字段类型保存为 `string | string[] | number | boolean | null`。
- [x] 删除字段只从当前模板快照移除，保留历史 `analysisFields` 键，避免静默篡改已有记录。
- [x] 固定字段 `shot_description` 继续复用既有“画面内容”笔记，不生成第二份数据。
- [x] 已执行 `pnpm.cmd run build`。

### 本阶段规则

1. 字段 `id` 创建后不因改名、排序或类型调整而改变。
2. 展示顺序只由 `order` 决定；不使用字段名称推导排序。
3. 选项是选择类字段的可保存约束；参考词仅辅助填写，不自动写入分析值。
4. 历史分析值即使对应字段被删除也保留在项目本地数据中，后续导出或恢复仍可使用。

## T9 模板与分析值规范化（已完成）

- [x] 新增模板规范化服务，统一清理模板名称、字段 ID、字段名称、选项和参考词。
- [x] 为字段、选项与参考词施加去重、空值过滤和数量上限，避免异常配置拖慢编辑器。
- [x] 分镜写入前按字段类型校验：单选/多选只保留当前允许的选项；数字仅接受有限值；布尔只接受 `true` / `false`；文本限制长度。
- [x] 模板读取、模板保存、单字段填写与分镜保存均使用同一套规范化规则。
- [x] 未出现在当前模板中的历史 `analysisFields` 键保持原样，不因模板变更丢失数据。
- [x] 已执行 `pnpm.cmd run build`。

### 参考结论

- JSON Schema 的做法是将类型、允许值与条件约束放在数据模型中，而不是分散到每个 UI 控件。
- 旧版 AisenLens 的字段/参考项去重和限额规则已被吸收；OpenReel 的类型、约束与 UI 提示分层也已吸收。
- OpenCut 没有可直接复用的可配置分析字段校验层，因此不引入其固定属性面板模型。

## T10 必填字段与分镜完整度（已完成）

- [x] 模板编辑弹窗可逐字段设为必填；该规则作为模板快照的一部分保存。
- [x] 新增统一完整度计算：按字段类型判断是否已填写，并列出未完成必填字段。
- [x] 右侧维度面板显示当前分镜必填项提示与字段填写进度。
- [x] 分镜列表显示每个分镜的填写进度；绿点表示必填项完成，黄点表示仍有必填项缺失。
- [x] 保存不被必填项拦截：缺项分镜保存为 `draft`，补齐后自动保存为 `confirmed`。

### 交互规则

1. “必填”是模板作者的完成标准，不是阻止创作者随时保存工作的限制。
2. `shot_description` 的完成度继续从现有“画面内容”笔记读取。
3. 多选至少选择一项才算已填写；文本去除空白后判断；数字 `0` 与布尔 `false` 都是有效值。
