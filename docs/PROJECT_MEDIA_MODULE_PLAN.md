# 项目与媒体管理模块拆分计划

## 目标

将当前项目库的演示 `localStorage` 数据替换为本地优先的真实项目记录，并建立“本地视频引用而非复制”的媒体关联基础。此阶段不实现分镜、波形、截图、自动切镜或视频替换迁移。

## 影响范围

- 项目库不再展示内置演示项目，改为读取本地项目仓库。
- 编辑器使用项目 ID 打开项目；无视频时显示媒体关联空状态，不显示演示时间线。
- 视频默认通过浏览器文件句柄引用，项目只保存指纹和元数据；原文件永不复制或删除。

## 约束

- 业务组件不能直接访问 IndexedDB、File System Access API 或 Object URL。
- 文件句柄和项目记录分仓保存；项目 JSON、备份和普通设置中不得保存句柄或视频二进制。
- 重新关联只接受指纹完全一致的文件；不实现静默替换。
- 删除项目只删除 AisenLens 的项目记录和句柄，不删除用户原始视频文件。
