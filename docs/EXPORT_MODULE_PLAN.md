# 拉片报告导出模块计划

## 首版范围

- 导出前预览分镜数量、分组章节和分析字段。
- 支持下载 CSV 分镜表，便于 Excel、Numbers 和表格工具继续编辑。
- 支持下载独立 HTML 报告；报告内嵌每个分镜的代表截图，可脱离 AisenLens 打开阅读。
- 所有文件仅由浏览器本地生成，不上传视频、截图或分析数据。

## 方案与依据

- 浏览器原生 `Blob`、`URL.createObjectURL()` 和下载链接足以生成文本报告，无需为首版添加表格或 PDF 依赖。
- OpenReel 的导出界面将设置、预览和实际执行解耦；AisenLens 同样将导出数据构建、文件生成和对话框 UI 分开。
- OpenCut 的导出交互在下载前明确格式和处理状态；本模块在 HTML 内嵌截图时显示生成状态，避免静默等待。
- 旧 AisenLens 的导出行同时使用镜号、时间、模板字段和分组章节；本模块吸收其报告行结构，但不复制其实现。

3. 新增版本化项目备份包与导入恢复流程；与报告导出保持独立。
