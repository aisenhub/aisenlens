# 分镜基础模块拆分计划

## 范围

将编辑器中原先仅用于演示的分镜状态替换为本地持久化的正式记录。当前阶段只实现手动分镜的基础保存与镜头级截图归属；自动分镜、模板快照、分组与 AI 分析将在各自模块中继续开发。边界调整通过右侧首尾帧控制完成。

## 当前规则

- 镜头以帧号保存；秒数只用于播放与界面显示。
- 第一次加载有视频但没有分镜数据时，创建一条覆盖完整视频的“未分析”镜头。
- 手动切分保留前段的镜头 ID，并为后段创建新 ID。
- 分镜编辑的截图、维度与笔记以镜头 ID 关联，不以列表位置关联。
- 删除镜头会合并到相邻镜头，避免时间线出现空档；完整的字段冲突处理会在分析/注释模块实现时补齐。
- 自动分镜入口当前禁用，不再生成随机演示数据，后续由可追溯的 AI 任务模块接入。
- 边界拖拽始终保持相邻两镜连续，每个镜头最少保留一帧；松开鼠标后才写入本地仓库。
- 手动切分仅能发生在当前镜头内部：前段保留原镜头 ID 与已有内容，后段使用新 ID 且分析、笔记和截图为空。
- 删除镜头会与相邻镜头合并，保留前镜头 ID；截图和自由文本合并到前镜头。结构化字段冲突处理将在模板模块落地后统一实现。

## 边界编辑方案

- 成熟方案调研：HTMLMediaElement 以秒提供定位接口，应用层以整数帧保存边界，避免浮点累计误差。
- OpenReel 参考：将切分和裁切统一路由到明确的领域动作，且仅在播放头位于片段内部时允许执行。
- OpenCut 参考：交互采用 preview / commit / discard 三阶段，并把时间投影到整数精度。
- AisenLens 融合：保留单视频连续镜头模型；拖动仅预览，松开后通过共享边界同时更新前镜的 `endFrame` 与后镜的 `startFrame`，不引入多轨裁切、吸附点或复杂撤销栈。
- OpenReel / OpenCut 切分参考：仅允许内部切分，前段保留原实体、后段取得新 ID；AisenLens 不复制后段的分析结论，避免错误继承。

## 手动验证

使用 `test/test.mov`：

1. 打开或新建项目并关联视频，确认编辑器出现一条完整镜头。
2. 在中间位置定位后点击“分镜拆分”，确认分为两个连续镜头。
3. 填写维度和批注、采集截图，返回项目库再重新打开，确认内容与封面仍在。
4. 删除其中一个镜头，确认剩余镜头覆盖完整视频且项目卡片镜头数更新。
5. 在右侧“画面调整”修改相邻镜头的首帧或尾帧，确认两镜连续、均至少一帧，刷新后边界仍保留。
6. 在镜头内部定位后执行切分，确认前镜保留内容、后镜为空；删除后镜，确认截图和笔记合回前镜并可刷新恢复。

## 修复记录

- 分镜保存曾在同一 IndexedDB 事务中并行清理旧记录和写入新记录，游标可能继续删除刚写入的新记录，导致刷新后内容消失。现已改为等待旧记录清理完成后再写入新记录。
- 刷新后本地视频句柄可能需要浏览器重新授权读取。现会显示“授权读取视频”，不再将该状态误判为需要重新关联文件。
- 当前页面与项目选择会保存在浏览器会话中，刷新后继续打开原项目；关闭浏览器标签页后回到首页是预期行为。
- 新建或切分出的镜头不会预填分析字段；未选择时界面明确显示“未填写”。
