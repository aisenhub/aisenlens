# 全站 UI 组件化迁移计划

## 原则

保持 AisenLens 的现有视觉与业务流程，将通用交互收敛到 `src/components/ui/`。编辑器的时间线、画布和连续调节等高密度专用交互保留定制实现，不强行替换为通用组件。

## 已完成

- [x] 接入 shadcn/ui 基础配置、语义主题 token 与全局通知容器。
- [x] 引入并复用 `Button`、`Dialog`、`Tooltip`、`Tabs`、`Input`、`Textarea` 与 `Sonner`。
- [x] 顶部导航使用统一按钮和图标提示；账户菜单使用稳定的受控浮层。
- [x] 项目库统一操作按钮、搜索输入、排序项和新建/删除弹窗。
- [x] 账户页统一登录、注册、密码重置、用户中心表单与弹窗控件。
- [x] 反馈页和支持页统一表单、选择卡片、支付确认弹窗和通知提示。
- [x] 落地页、术语页、更新日志、用户协议和隐私政策的通用交互已组件化；纯展示图解保持定制实现。
- [x] 编辑器的项目库设置已迁移到共享弹窗与操作按钮。
- [x] 编辑器工作台的顶部操作、工具栏、侧栏操作、分析维度、帧控制、分镜列表、注释输入和分析标签页已统一使用现有组件库。
- [x] 编辑器时间线镜头块与自动分镜范围滑块保留原生实现，避免影响高密度定位和连续调节体验。
- [x] 编辑器预览画布、波形、帧带、时间标尺和镜头时间线已拆分为专用组件，工作台仅负责状态与事件编排。
- [x] 编辑器分镜色块使用全站主题 token：未播放、已播放、当前选中和标记状态均适配深浅主题。

## 验收

- [x] 每个已迁移阶段均通过 `pnpm.cmd build`。
- [x] 深浅主题下保持可读性与对比度。
- [x] 未新增重复业务逻辑或局部主题入口。
