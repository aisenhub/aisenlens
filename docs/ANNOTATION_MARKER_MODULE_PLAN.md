# 分镜标记与注释模块

## 本轮完成

- [x] 新建独立的 `AnnotationMarker` 实体，以稳定 ID、项目 ID、帧号、可选分镜关联、分类、标题、说明和时间戳保存标记。
- [x] 使用 IndexedDB 的 `annotation-markers` 仓库持久化标记；项目删除时一并删除其标记。
- [x] 支持重要镜头、构图精妙、情绪高点、转折点四种分类。
- [x] 编辑器左侧视频工具中可在当前帧创建标记，并可编辑标题/说明、删除或点击跳转。
- [x] 时间尺显示分类色标，点击色标可跳转到对应帧。
- [x] 移除分镜 `marked` 布尔状态；一个分镜可关联零至多个独立标记，不再把标记限制为单一状态。

## 数据与交互规则

1. 帧号是标记唯一的时间定位依据，避免浮点秒数在不同显示与计算间产生偏差。
2. `shotId` 是创建时的可选上下文，不以分镜边界变化反向移动标记；标记始终留在它的原始视频帧。
3. 同一帧可拥有多个标记，便于从不同分析角度记录画面。
4. 标记说明为可选文本，不替代分镜的画面描述与镜头分析。

## 参考结论

- MDN IndexedDB：适合在浏览器中以对象仓库保存可查询的本地结构化数据。
- OpenReel 的 `marker-slice.ts` 和 `MarkersPanel.tsx`：标记应独立于剪辑实体，提供新增、编辑、删除、排序、跳转的一致操作链路。
- OpenCut 的书签命令：将书签定位归一为帧时间，避免直接以浮点秒数作为持久化位置。
