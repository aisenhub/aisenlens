## 集成负责人检查

- C1 稳定ID、来源和存储契约未冻结前，不让不同 agent 各自创建自己的草稿模型。
- C2 播放器与 C3 coverage 共用事件源；不能各自维护一套 currentTime。
- 只有集成负责人修改 repository 事务、EditorWorkspace 连接与 autosave 互斥。
- 跨 agent 的“已通过”需附命令/环境/输出摘要，不能只凭口头完成。
- 不自动创建新 Codex 任务或替用户派发消息；本文件仅为可复制执行指令。
