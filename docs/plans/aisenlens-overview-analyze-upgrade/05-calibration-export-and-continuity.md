集成负责人独占修改 projectRepository/types、projectRecoveryService、实际项目备份/导入服务、editor persistence/history、校准draft应用链、group reconcile、reportExportService/xlsxExportService/groupExportService、Learn deriveLearningSources和workflow返回入口。

## 2. 校准往返

深拆“校准此处”flush目标内容→保存返回scope/target与媒体时间→进入校准并定位。取消或未应用返回原正式研究状态；成功后按新正式版本重新解析。

媒体锚定研究范围的startUs/endUs不随Shot编号变化，成员重新投影。基于Group的scope跟随该Group合法新范围。Shot目标ID仍存在则保留；ID消失显示“原镜头结构已变化”，保留原媒体位置与研究内容，用户选替代目标，不自动跳相同序号。

复用现有applyCalibrationDraft原子提交边界，纳入受影响研究引用/needsReview更新。不能正式结构提交后再异步补研究状态，造成崩溃后不一致。相关正式编辑/校准命令、undo和导入均使用同一重整服务。

## 3. 引用与内容处理规则

| 变化 | 必须保持的行为 |
| --- | --- |
| 移动边界但ShotID不变 | 原正文与证据保留；相关完成状态标needsReview；素材时间范围不改 |
| 补切 | 范围成员更新；现有校准保留左ID/新右ID策略接入；新Shot不继承“研究完成” |
| 合并/删除Shot ID | 不丢原正文与上下文；引用可按可靠lineage解析，否则保留原锚点与unresolved状态供核对 |
| Group不再合法 | title/summary/研究元信息保留为待修正对象，不继续reconcile flatMap静默删除；正常地图与问题列表区别展示 |
| 用户明确删除Group | 对有关研究内容提供保留为媒体范围记录的默认方案及影响预览；确认纯删除才删除该目标内容，不删Shot/截图 |
| 截图或音频源被删除 | 留下失效引用说明，正文不丢；不能偷偷指向同序号资源 |
| 音轨移动/裁切 | 按源媒体范围重新映射，超出可播放区域标不可用，不把旧项目时间当新声音 |
| 换媒体/错误重新关联 | 身份不匹配阻断自动解析；不能用同文件名继承研究内容 |

内容转成范围记录是当前用户删除操作的保留动作，不是旧格式兼容层；需要独立命令、一次Undo和明确预览。校准已有内容保留机制优先扩展，不能再造另一套archive。

## 4. 保存、历史与并发

项目统一写队列协调正文/研究元信息/结构/校准。expected project version、目标version与媒体身份在事务内复验；失败不更新内存“已保存”。保存过程中切项目的回调不能写另一个项目store。

范围/结构/研究内容命令纳入适当编辑历史；保存去抖不等于每字一次history，沿项目已有分组策略。模式、筛选、播放和滚动不入history。应用校准一次Undo恢复完整正式文档与相关研究状态，之后重新派生总览与scope。

跨标签冲突保留本地草稿并提示，不自动覆盖；完成状态与正文同操作失败一起回滚。存在旧autosave整对象写时必须同步当前基线，防止覆盖新实体或已提交引用。

## 5. 备份、快照、导出与Learn

- 完整项目备份与恢复快照包含新范围/元信息/无效引用说明及必要资源引用；派生缓存可不包含，用户截图不可随意排除。
- 导入校验新实体、重映射project/对象/资源ID；同一备份导入两次彼此隔离，不引用原项目。
- 项目删除同步清理新stores和资源引用，不泄露孤儿数据；缓存清理不清用户研究。
- 报告保留旧Shot字段/笔记/截图，增加范围研究附录或对应章节，带真实时间与证据来源；不是只在网页可见。
- Excel若已有导出，新增独立范围研究表/引用表而不修改原列含义；缺失引用如实注明。
- 视频导出沿现有能力，不能为了本期新增字幕/AI渲染；确保校准后源时间与原overlay结果不回归。
- Learn汇总现有Shot、Group和新范围的真实内容，链接到同一research导航；不复制正文进Learn。

具体备份格式使用当前版本校验，不新建旧数据兼容分支。对已有合法内容保持项目现有读取行为，不为删除历史兼容代码扩展本次范围。

分别注入正文、元信息、结构、校准引用写失败，确认重载没有半成功；验证保存最新笔记立刻校准与快照一致。关闭页面发生在tx提交后但UI更新前，重进按数据库正式版本恢复，不重复创建范围。
