## 2. 影片地图与时间语义

所有轨道共享真实媒体时间轴：镜头、结构、标记、研究范围、局部密度。镜头位置由startTime，宽度由duration；去掉每镜最少1%宽度。小镜头可扩大透明命中区/使用最近边界选择，但不改变视觉时长；密集区域聚合绘制并可放大。

图例和坐标显示真实单位，未建立结构不造Scene；缺媒体时可用已持久化可靠时间显示地图，不能播放/取新帧。时间未可靠时文字内容可读，相关统计显示不可用，不能默用30fps。

统一派生数据来源：经O0验证的frame→PTS（优先）或已有可靠媒体时间；同一选择、图形与统计只走一个适配器。正式镜头未覆盖完整视频时显示覆盖范围/缺口，不能把缺口当一段长镜头。

### 冻结统计口径

- 全片平均/中位/最短/最长基于有效完整Shot时长；偶数中位数为两个中值均值。
- 局部选区展示“相交镜头数”和“选区时长”；镜头时长统计基于相交Shot的完整时长，明确标签，不截短边缘镜头后冒充原镜时长。
- 全片切点密度 = 覆盖有效视频时间内的唯一内部正式边界数 / 有效时间分钟；有覆盖缺口时明确所用覆盖分母，不用未知区域推断切点。
- 局部密度采用固定10秒分箱 `[0,10),[10,20)…`；末箱按真实箱长归一化成cuts/min，显示原始计数与实际窗口长度。影片0起点和末尾哨兵不算切点，内部边界落箱起点计入该箱，跨箱不重复。
- 框选统计的切点只计严格位于范围内部的边界；与上述分箱边界归属区别写进测试和帮助说明。
- 不把密度命名情绪，不用平滑曲线造精度；窗口变化若后续支持需显式标明。

## 3. 用户动作

1. 单击镜头/结构卡片：选中并就地预览，不立即跳stage。
2. 点击播放：在当前目标范围播放，可暂停并选择另一个目标。
3. 拖选或通过起止时间输入选择范围，显示其时间/镜头数；无需先建Scene。
4. “深入研究”：O2命令携带范围/选择和返回上下文，进入O4范围模式。
5. “逐镜记录”/“继续上次研究”：进入已保存的顺序队列或有效研究目标。
6. 点最长/最短镜头指标：定位实际对象；多项同值可先定位第一项并允许浏览匹配列表，行为一致。

不为每次拖选生成持久记录；有研究内容或明确保存时交O1创建。没有内容选区可直接URL传范围。

## 4. 同页结构操作

选镜头或时间范围→选择Scene/Sequence/Section→预览成员→命名→提交。由时间选区建结构时吸附到相交正式Shot完整范围，并显示扩展后的起止；用户确认才创建，不能暗中改变范围。

Structure切换显示三层；卡片展示真实代表图、名称、媒体时间、成员数、摘要及真实研究状态。代表图优先既有主截图，其次安全派生帧；无图可重试而不是统一ImageOff占位。

同页支持标题/summary、成员范围、类别调整与删除，调用O1校验。非法交叠即时说明哪段冲突并保留输入；删除结构不删除Shot和笔记，关联研究元信息按O5归档/失效规则处理。复杂失效结构可读并进入修正，不在地图当正常Scene显示。

## 5. 状态与响应式

- 无Shot：解释建立镜头地图入口，不造统计；已有分析仍可读。
- 无结构：同页创建入口，也可直接选段研究。
- 预览加载/解码失败与文字读取独立，不整页转圈。
- 保存中禁止重复命令；失败保留输入并重试。
- 桌面预览与地图共存；窄屏预览折叠但“深入研究”和范围信息可达。
- 选择可用键盘与时间输入完成，不要求只能拖动；真实焦点与选中态，状态不只靠色彩。
