# 前端架构拆分计划

## 目标

在不改变现有页面、演示数据和交互的前提下，将 Figma Make 生成的单层 React 应用迁移到可维护的模块结构。当前项目已接入 Supabase Auth，项目与编辑器数据仍按产品决策保存在本地。

## 现状分析（已完成）

- [x] 入口为 `src/main.tsx`，全局样式集中在 `src/index.css`。
- [x] `src/App.tsx` 同时承载页面切换、全局导航、认证演示状态和三个弹窗（564 行）。
- [x] 应用使用数值页面标识进行单页切换，尚未使用路由库；为避免引入依赖，本次保留该导航机制。
- [x] 页面位于 `src/pages/`，其中 `TutorialsPage.tsx`（1485 行）、`EditorPage.tsx`（1096 行）和 `LandingPage.tsx`（621 行）为主要拆分目标。
- [x] 项目未安装 Zustand，且现有状态均为页面内演示状态；本次不强行加入全局状态库。
- [x] Supabase Auth 已通过 `src/services/supabase/` 接入；项目数据、存储与 AI 服务仍待按需求逐步接入。

## 目标结构

```text
src/
├── app/                 # 应用初始化、导航状态与页面装配
├── components/layout/   # 站点级可复用导航
├── constants/           # 页面与导航常量
├── features/
│   ├── auth/            # 注册、用户中心演示界面
│   ├── editor/          # 编辑器与编辑器设置
│   ├── project/         # 本地项目库与文件夹管理
│   ├── marketing/       # 落地页展示内容
│   └── tutorials/       # 教程展示内容
├── pages/               # 仅保留页面级装配入口
├── types/               # 跨模块共享类型
└── main.tsx
```
