## 归档资料

归档目录按来源和用途继续分类：

- `archive/plans/`：功能改造计划、阶段计划和验证记录。
- `archive/chaifen/`：Web 拆分执行包、提示词和切换清单。
- `archive/lensflow/`：旧产品研究、流程、UI 与设计规划。
- `archive/auto-shot/`：自动分镜历史实施计划。
- `archive/audits/`：带日期的审计快照。
- `archive/optimization/`：已结束的工程优化总计划。

归档内容用于追溯，不作为当前实现或新任务的直接执行指令。
