# 真实帧截图模块拆分计划

## 范围

本模块从当前播放视频采集真实画面，保存为独立本地截图资源，并在编辑器中读取和展示。首尾帧编辑、批量帧带、自动封面选择和分镜截图归属将在后续分镜/帧图模块继续开发。

| 阶段 | 落点 | 工作 | 状态 |
| --- | --- | --- | --- |
| S1 | `features/project/types.ts` | 截图元数据与资源仓库接口 | [x] |
| S2 | `features/project/services/screenshotService.ts` | 真实视频帧 Canvas 编码、截图二进制与元数据分仓 | [x] |
| S3 | `features/editor/components/` | 右侧画面面板显示真实截图并触发采集 | [x] |
| S4 | `features/project/components/` | 项目卡片使用已捕获截图作为稳定封面 | [x] |
| S5 | 验证 | 生产构建与测试视频手动采集验证 | [~] |

## 实施记录

- 截图通过 Canvas 从原生视频当前呈现画面采集并编码为 JPEG；保存时将元数据与 Blob 分别写入 IndexedDB 仓库。
- 当前截图可在右侧“画面”面板查看，采集后会更新项目的稳定封面；项目库卡片读取已保存截图而非使用演示封面。
- 项目删除时会清理该项目的截图元数据与二进制资源；镜头级截图归属将在正式分镜实体实现后接入。

## 约束

- 截图必须从当前 `HTMLVideoElement` 的已呈现画面采集；不能生成装饰性假图。
- 截图 Blob 与结构化项目记录分开保存；项目删除时一并清理。
- 当前截图暂作为项目级资源与项目封面，后续镜头 ID 稳定后再绑定到正式 `Shot`。
