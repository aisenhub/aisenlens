范围：Web 总览（Overview）、深拆（Analyze）及直接相关的结构、研究上下文和分析记录。

## 1. 文档用途与决定状态

本文将本次对话结论固化为后续 agent 生成执行计划的架构输入，不是阶段实施报告。用户已明确：

- “按顺序逐镜记录”和“带问题选段研究”同等重要，必须顺畅切换。
- 总览负责全局理解、结构组织与研究入口。
- 深拆负责在选定上下文内观看、对照、记录证据与形成解释。
- 两页共享同一套正式数据，不因页面或研究模式切换复制镜头与笔记。

下文“目标/规则”是本次确定的架构方向；“当前事实”来自源码检查，不代表浏览器已实测；“待细化/验证”需要后续计划阶段依据代码落实，不应被写成已确认的数据库字段或已实现能力。

本轮只编写文档，不修改产品代码、不进行部署或 Git 提交。工作区存在进行中的校准改造，后续 agent 必须重新核实实际代码与提交状态，不能覆盖已有工作。

## 2. 核心问题与目标

当前页面已经划分总览、Scenes、Shots、Sound，但研究行为仍分散在不同页面组合中。用户为了找内容、播放、截图、写笔记、整理结构需要频繁切换，并可能失去原范围和位置。

目标用户循环：

> 总览观察与选范围 → 深拆观看与记录 → 回到上下文验证解释 → 总结研究结果 → 返回总览继续定位。

同时支持另一入口：

> 从上次镜头继续逐镜记录 → 发现值得研究的连续片段 → 临时进入范围研究 → 返回原顺序队列继续。

成功不以用户填满所有字段或建立所有场景为前提。用户应能直接研究一个镜头或任意时间范围，也能系统完成整片逐镜记录。

以下路径相对仓库根；实现事实截至本轮读取的本地工作区。

### 3.1 统计语义问题

`deriveFilmOverview.ts` 当前有以下需要修正的行为：

- 偶数样本中位数取上中值，应取中间两项均值。
- `cutsWindowSeconds=10` 没有参与局部密度计算，返回的数值是全片平均 cuts/min；界面不应将其描述为10秒窗口统计。
- 统计与地图分别使用帧范围/shot.duration，需统一可靠时间来源及不可用状态。
- 地图需要真实时间坐标，最小点击区域可扩大，但不能改变视觉时间比例。

这些属于研究入口的正确性要求，不是单纯视觉优化。

## 4. 总览与深拆的职责边界

| 能力 | 总览 | 深拆 |
| --- | --- | --- |
| 全片结构、节奏分布 | 主责：浏览、对照、定位 | 展示当前范围上下文 |
| 建立/调整场景和段落 | 主入口，就地完成 | 可快捷调用同一结构命令 |
| 内容预览 | 支持轻量预览，不强制跳页 | 持续观看与精细操作 |
| 选择研究范围 | 主入口之一 | 可从顺序队列临时选段 |
| 逐镜记录 | 显示状态、继续入口 | 主责 |
| 截图、标注、自定义字段 | 展示已有结果 | 主责，复用现有能力 |
| 前后镜关系与声音关系 | 汇总有来源的发现 | 主责，基于画面/声音证据 |
| 场景/范围总结 | 展示并导航回源 | 撰写与编辑 |
| 镜头结构校准 | 展示状态和校准入口 | 发现问题后定位进入校准，返回原研究位置 |
| 方法沉淀 | 展示已有研究成果 | 保留来源与解释；未来技法实体仍归 Learn |

两页不是严格的一次性流水线。用户可以从任一页继续研究，切换不应复制数据、重置筛选或丢失编辑草稿。

## 5. 拉片内容模型

### 5.1 四类内容

| 类别 | 示例 | 来源与可信度要求 |
| --- | --- | --- |
| 素材事实 | 帧范围、时长、画面、原声音 | 来自媒体与正式镜头结构，标明可靠时间基准 |
| 观察/标注 | 景别、运镜、人物动作、声音出现时刻 | 标明用户记录或实际检测来源，不默认为客观真值 |
| 解释 | 为什么此时切换、如何引导注意力、可能产生何种效果 | 用户解释与机器建议有区别，关联证据 |
| 组织/总结 | 场景结构、范围总结、研究结论 | 与所依据的镜头或范围关联，可回到原处 |

不能把“字段已填写”当成解释正确，也不能用镜头变短直接生成“情绪高潮”。

### 5.2 分析对象

目标支持：镜头、场景/结构范围、任意研究时间范围。

一个分析记录可能涉及单镜内部变化、前后镜组合或声画跨边界关系。因此，逐步支持稳定对象引用、时间范围和证据引用，而不将所有内容强塞到当前 Shot 的文本字段中。

典型记录：

- 研究问题：这一段为什么越来越紧张？
- 观察：镜头时长缩短、视线反复切换、音乐先于画面进入。
- 证据：相关 shot ID、截图 ID、声音发生位置。
- 解释：这些安排如何影响观众的期待。
- 总结：该范围内得到的结论及仍待核实的问题。

不要求每条笔记都填写上述全部字段。用户可以快速记录，随后补充证据和解释。首轮不建设知识图谱或独立关系编辑器。

### 5.3 现有内容保留

现有 `shotNotes.content/analysis`、`shotDims`、模板字段、截图、Group summary 等保持有效并由统一读写入口承载。新检查器不能为了简洁丢掉现有字段、缩减报告内容或建立平行笔记副本。

场景写作提示可以先辅助现有摘要；若后续拆分 Objective/Conflict 等字段，必须真的具有独立模型、保存与导出语义，不能把多个输入框都绑定同一个 summary。

具体分析记录类型与持久化结构由后续执行计划冻结。不得将本节概念名直接当成已存在接口。

## 6. 研究范围与正式结构

### 6.1 研究范围

研究范围是当前工作范围，不等于影片叙事结构。

- 可以是全片、已有场景或用户选定的连续时间范围。
- 可以跨场景，与其他研究范围重叠。
- 无须先命名为 Scene 才能研究。
- 仅改变工作范围不复制镜头或已有笔记。
- 一旦范围上存在用户问题、总结或其他记录，必须可保存、恢复与回源；纯临时选择属于会话状态。
- 用户可将适合的范围明确保存为正式结构；不可自动将每个研究范围转成场景。

### 6.2 正式结构规则

取代当前跨 kind 全互斥约束：

- Scene 允许一个或多个连续镜头。
- 同一套场景划分内部避免相互交叠。
- Sequence 等更高层结构可以覆盖多个 Scene 的镜头。
- Section 的产品含义需在计划阶段明确，不强制所有作品采用固定 Film→Sequence→Section→Scene 树。
- 初期可采用分层范围及校验，不要求立即建设通用嵌套树编辑器。
- 跨层覆盖不等于随意跨界父子关系；显式父子关系如需引入，应有包含约束与验证。

本次不自动扩展为多套互相竞争的场景划分系统。用户临时比较、主题性范围优先由研究范围承载。

结构改动会影响 groupService、reconcile、仓储、导出和校准后的关联重整。必须统一修改领域规则，不能只解除界面按钮限制。

## 7. 总览目标架构与交互

### 7.1 影片地图

围绕同一时间坐标组合：

- 正式镜头分布。
- 人工结构范围。
- 镜头时长或真实局部切点密度。
- 已有标记、研究范围与研究记录。
- 上次研究位置和继续入口。

主要交互：

1. 单击镜头/场景：在总览内预览并选中。
2. 拖选连续范围：展示范围时间、镜头数和适用统计。
3. 点击“深入研究”：携带范围和选择进入深拆。
4. 点击可定位指标：定位真实对象，例如最长镜头。
5. 返回总览：恢复原视图、选区、缩放、滚动和筛选。

抽样缩略图与统计只帮助发现位置，不证明内容已被人工研究。长片显示需控制密度与可见对象数，不为每个镜头强行占固定百分比。

### 7.2 结构视图

就地完成：选范围/镜头 → 创建结构 → 命名/简要摘要 → 调整成员 → 深入研究。

卡片使用实际代表截图或派生缩略图；缺图时显示真实缺失状态。显示时间、成员数、摘要和已有研究状态。展示已支持的结构类别，不能只把所有类别数量汇总却只渲染 Scene。

总览保留结构编辑入口，深拆的快捷结构操作调用同一服务，不各维护一套结构数据。

### 7.3 内容边界

情绪曲线、人物线、叙事节拍、技法聚合只有真实来源时展示。未实现能力不生成空轨道、示例人物或假分析结果；不把这些后续能力作为当前双页流畅性的前置。

## 8. 深拆目标架构与交互

### 8.1 稳定的观看工作区

深拆保留同一交互播放器、播放状态和局部时间线。Scenes、Shots、Sound 改变导航/分析重点，不替换成失去播放器的独立页面。

推荐布局：

```text
返回总览 / 当前研究范围         全片顺序 ↔ 范围研究
----------------------------------------------------------------
导航与筛选           播放器                  对象检查器
场景/镜头            播放、逐帧、截图         观察、字段、解释
                     前镜/当前/后镜证据       证据引用、总结
----------------------------------------------------------------
范围内镜头带 / 时间线 / 声音与标记
```

桌面分区、窄屏面板可以不同，但观看、记录和导航使用同一个会话。延续现有 Cinema/Studio token 和组件系统。

### 8.2 显式对象检查器

- 用户选中场景：显示场景范围、摘要、研究与成员入口。
- 用户选中镜头：显示镜头证据、已有模板字段和笔记。
- 用户选中研究范围：显示该范围的问题、证据与总结。
- 用户选中声音标记等对象：显示对应已有能力的详情。

所属场景仅是上下文，不覆盖镜头选择。需要按对象类型分派，而不是 `group ? SceneInspector : ShotInspector`。

### 8.3 证据与上下文

接入已有首尾帧、代表图、用户截图和自定义模板；围绕当前范围提供前后镜对照与连续回放。截图和标注仍使用原有服务、稳定 ID 与导出路径。

局部研究默认强调范围内成员，但允许查看范围外前后上下文；超出范围时明确标识，不悄悄改变研究目标。

### 8.4 声音研究

保留画面与镜头边界，支持结合波形/已有音轨观看、定位、标记及记录声画关系。音轨导入、排序、分割和调整为辅助管理能力。

没有 ASR 或声音分离时可以人工标注，不假称识别了对白、音乐或音效。声画事件可跨镜头边界，不能因当前镜头变化就截断证据关系。

## 9. 两种工作流程

### 9.1 全片顺序逐镜记录

1. 从上次位置或指定镜头进入全片顺序队列。
2. 播放镜头及必要前后上下文，可选择连续播放或逐镜停止。
3. 截图、标注、记录解释，保存动作绑定当前编辑对象。
4. “保存并下一镜”推进当前明确队列。
5. 筛选存在时显示队列范围与位置，不暗中使用另一套顺序。
6. 遇到值得研究的片段，选择连续范围进入范围研究。
7. 返回顺序记录时恢复原队列、筛选、镜头与滚动位置。

逐镜记录不强制先建立场景；没有场景时提供全片镜头入口，不伪造 Scene。

### 9.2 带问题选段研究

1. 在总览或深拆选择现有场景/任意连续范围。
2. 可选填写研究问题，进入范围研究。
3. 整段观看，逐镜/声画对照并收集证据。
4. 写解释与范围总结；已有镜头笔记直接复用。
5. 按需将范围保存为结构，不强制执行。
6. 返回总览，结果在相应范围可见且可再次进入。

两种方式同等重要，使用同一份内容。模式切换是视图与工作范围改变，不是新建项目或复制分析。

## 10. 共享研究上下文

### 10.1 三种状态必须分离

| 状态 | 示例 | 规则 |
| --- | --- | --- |
| 研究范围 | Scene 08 / 全片 / 01:20–02:05 | 控制导航队列、局部统计与时间线范围 |
| 编辑/检查对象 | Shot 037 | 写入绑定稳定对象 ID |
| 播放位置 | 已播放到 Shot 038 | 由唯一播放时钟管理，不自动改写编辑目标 |

用户输入时锁定编辑对象；提供明确“跟随播放”开关。自动跟随不能把未保存文本写到下一镜。切对象时保存或保留原对象草稿，错误可见，不静默丢弃。

### 10.2 状态归属

- 正式领域数据：镜头、结构、分析、截图、标记，经服务与项目仓储持久化。
- 项目作用域 Zustand 会话：研究模式、当前范围、显式选择、导航队列、各视图状态、返回位置。
- 媒体运行对象：video、decoder、Blob URL 等由既有媒体生命周期管理，不作为持久化数据。
- 可恢复编辑草稿：绑定 project/object ID 和版本，按已有保存架构扩展。

URL 表达可恢复导航目标，内存/本地会话保存高频视窗状态；具体字段由执行计划冻结，不把每帧播放时间写浏览器历史。浏览器返回与界面返回都应恢复合理上下文。

对象删除或校准后 ID/范围变化时，必须按稳定身份与正式版本重定位或提示失效，不凭列表序号定位其他镜头。

## 11. 进度与成果语义

分别表示：

- 字段填写情况：已有模板 completeness 的真实含义。
- 已记录镜头数：有用户记录，不等于内容正确。
- 范围研究状态：问题/总结/用户明确完成状态。
- 待研究事项：用户留存的问题。

不将这些混成“影片理解68%”。总览汇总同一份来源数据；深拆修改后同步反映，不保存另一套派生进度真值。

## 12. 与校准及现有能力的衔接

校准负责结构正确性，深拆负责研究内容。在深拆发现漏切或边界错误时，应能定位进入校准并返回原研究上下文。既有快捷结构修正若保留，必须遵循统一领域命令与引用规则，不形成第二种镜头结构语义。

校准成功后：

- 总览统计和范围成员随正式版本更新。
- 原笔记、截图、标记与结构按统一引用规则保留或标待复核。
- 临时研究范围不能因镜头重编号而跳到错误内容。
- 场景/Sequence 规则调整须同步校准相关 reconcile 与测试。

已有校准计划是相关输入，但当前工作区仍有未提交实现。后续计划先检查实际完成状态，再复用媒体时间、草稿应用及引用处理能力；不重复实现，不假定已全部验收。

## 16. 可观察的验收方向

- 总览点场景可就地预览，显式进入深拆后范围/目标正确，返回恢复原视窗。
- 全片顺序记录可进入局部研究，再返回原队列；只有一份笔记。
- 已分组镜头可正常编辑镜头内容，选场景才显示场景检查器。
- 播放越过下一镜时，正在输入的内容不被写到其他对象。
- Scenes/Shots/Sound 切换保留可用的观看上下文，不重复创建交互播放器。
- 没有场景也能逐镜或选段研究；单镜场景和跨层覆盖规则正确。
- 所有已有字段、笔记、截图、导出与恢复链完整。
- 校准重整后数据引用与研究范围不乱跳。
- 中位数、时间比例和局部密度的结果与标注单位一致。
- 没有真实来源时不展示假情绪/人物/智能分析。

后续执行计划应将本节转成领域、浏览器与数据恢复用例，按实际风险选择测试，不在本文预填通过记录。

## 17. 研究依据

- [Cinemetrics：The Metrics in Cinemetrics](https://cinemetrics.uchicago.edu/article/616e7ecc-7915-4768-b84d-7dec79aa77c2)：镜头时长分布和统计可辅助观察，必须结合影片内容解释。

- [Columbia：Shot, Scene, and Sequence](https://filmglossary.ccnmtl.columbia.edu/term/shot-scene-and-sequence/)：镜头与更高层叙事组织是不同分析层次，不等同软件编辑器的 Scene 实体。
