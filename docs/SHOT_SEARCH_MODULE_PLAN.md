# 项目内分镜检索与筛选模块计划

## 首版范围

- 分镜列表支持按镜号、分组名称与总结、画面描述、分析笔记、模板分析字段和标记文字即时检索。
- 可按场景、段落、序列筛选，并可只查看有批注、有截图或已有标记的分镜。
- 筛选显示“匹配数 / 总数”；没有结果时给出明确空状态。
- 点击结果同时定位当前分镜和视频播放头；筛选结果不改变真实分镜顺序、分组或持久化数据。

## 实施选择

- 筛选计算位于 `features/shot/services/shotSearchService.ts`，列表组件只持有瞬时筛选状态和渲染。
- 使用现有已加载的项目数据做内存派生，不增加 IndexedDB 索引、服务端 API 或依赖。
- 筛选期间即使所属分组原本折叠，也展示其中匹配的分镜，避免结果被隐藏。

## 后续迭代

1. 增加按时间范围、分镜状态、自动检测置信度和模板字段的精确筛选。
2. 支持保存常用筛选视图，并在报告导出中复用筛选结果。
3. 在转写与 AI 建议落地后，加入全文检索、命中片段高亮与语义检索。
