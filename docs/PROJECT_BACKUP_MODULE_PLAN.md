# 项目备份与恢复模块计划

## 首版范围

- 导出版本化 `.aisenlens-backup.zip` 包，包含项目、分镜、模板、分组、批注与截图二进制数据。
- 导入前严格验证格式与版本；导入创建全新项目并重映射资源 ID，绝不覆盖现有项目。
- 本地视频不进入备份，因为浏览器文件句柄不可移植且视频通常过大；恢复项目保留媒体指纹并提示重新关联。

## 调研结论

- OpenReel 的序列化器以版本号、结构校验和缺失媒体占位区分项目描述与媒体数据。
- OpenCut 以明确迁移链处理历史项目格式；首版仅接受当前版本，避免未验证的隐式兼容。
- 旧 AisenLens 将项目数据、截图资源和媒体资源拆分，导入时先校验清单；本实现沿用资源独立与校验原则，使用无压缩 ZIP 将截图保持为二进制条目，避免 Base64 JSON 的浏览器字符串长度上限。

## 后续迭代

1. 为 ZIP 资源加入 SHA-256 校验和、体积预检和可选视频副本。
2. 为历史格式增加逐版本迁移器。
3. 增加三份自动恢复快照与异常恢复入口。
