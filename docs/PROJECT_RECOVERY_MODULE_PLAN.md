# 自动恢复与存储管理模块计划

## 首版范围

- 编辑器打开后立即创建一份轻量恢复快照，并每 30 秒更新；每个项目仅保留最近三份。
- 快照仅保存项目、分镜、分组、批注和模板等结构化数据，不复制视频、截图、波形或时间线缩略图。
- 项目卡片提供“恢复与存储”入口，可查看快照、恢复所选版本、查看浏览器估算用量，并清理波形和帧缩略图缓存。
- 恢复会覆盖目标项目的结构化数据，但保留本地视频关联和截图资源；若快照没有模板，则同时移除当前模板。

## 调研结论与实施选择

- 浏览器 `navigator.storage.estimate()` 可提供尽力而为的配额与已用容量，适合作为本地存储提示，不能作为精确计费数据。
- OpenReel 将恢复点作为轻量项目状态，并由编辑器恢复入口展示；其模式适合“自动保存但不复制媒体”的本地优先边界。
- OpenCut 将配额检测、项目元数据和派生缓存分开管理；可再生成数据应优先被清理。
- 旧 AisenLens 的存储诊断验证了将项目结构、资源和缓存分层统计的必要性，但本版不复用其实现。

## 数据与边界

| 数据类别 | 自动恢复快照 | 清理缓存 |
| --- | --- | --- |
| 项目、分镜、分组、批注、模板 | 保存 | 不清理 |
| 本地视频与文件句柄 | 不保存 | 不清理 |
| 截图与导出代表图 | 不保存 | 不清理 |
| 波形、时间线帧缩略图 | 不保存 | 可清理并按需生成 |

## 后续迭代

1. 在快照列表中显示分镜、分组和批注数量，帮助用户确认恢复点。
2. 依据访问时间实现缓存 LRU 清理与容量阈值提醒，而不是全量清理。
3. 在崩溃重开时提供最近快照的显式恢复提示；恢复前可增加结构化差异预览。
4. 为恢复写入增加事务化预检与失败诊断，覆盖低配额、损坏记录等异常。
